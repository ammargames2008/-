سبب المشكلة
-----------
أداة تحويل HTML إلى APK التي استعملتها تصنع WebView بسيط بدون "نافذة اختيار الملفات"،
لذلك زر (اختر ملفات) و 📎 لا يفعلان شيئاً داخل الـ APK رغم أنهما يعملان في المتصفح.

هذا المشروع هو نفس تطبيقك (app/src/main/assets/index.html بدون أي تعديل) داخل غلاف
أندرويد يضيف: اختيار الملفات (PDF/صور/نص)، المايك والكاميرا، وحفظ ملف PDF الناتج
في مجلد التنزيلات.

طريقة بناء الـ APK
------------------
الطريقة 1 (من الكمبيوتر - الأسهل):
  1) ثبّت Android Studio.   2) File > Open واختر مجلد MedTerms وانتظر المزامنة.
  3) Build > Build APK(s).  الملف يظهر في app/build/outputs/apk/debug/app-debug.apk

الطريقة 2 (بدون تثبيت أي شيء، عبر GitHub):
  1) أنشئ حساباً مجانياً على github.com وأنشئ مستودعاً جديداً (Repository).
  2) ارفع كل محتويات المجلد (مع المجلدات، ومنها .github) عبر Add file > Upload files
     (يفضّل من الكمبيوتر أو وضع "موقع سطح المكتب" في المتصفح).
  3) افتح تبويب Actions > Build APK > Run workflow، وانتظر 3-5 دقائق.
  4) افتح التشغيل المكتمل ونزّل MedTerms-APK من قسم Artifacts، فك الضغط وثبّت app-debug.apk.

ملاحظات
-------
- بيانات التطبيق القديمة (المفاتيح/التقدم) لا تنتقل من الـ APK القديم، أدخل مفتاحك من جديد.
- التطبيق يحتاج إنترنت لتحميل مكتبتي PDF.js و jsPDF (كما في نسختك الأصلية).
